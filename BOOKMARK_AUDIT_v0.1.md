## Current Active Direction

### Software Development

- Keep the active stack very small.
- **Use Now:** `javascript.info` for the JavaScript semantics gaps found in the baseline.
- React / TypeScript / Next.js / Full Stack Open stay **Later** until the JavaScript foundation is more stable.
- DSA resources stay **Later** because DSA currently appears largely not learned, not merely forgotten.
- Testing should be added to the learning path as a skill area; bookmarks do not currently provide one clearly dominant testing curriculum.

### IELTS / English

- Existing resources are already more than sufficient; do **not** search for more IELTS resources yet.
- Keep a minimal active stack: official IELTS preparation/sample material, one structured course if access is active, and output practice for speaking/writing.
- General BBC/Cambridge/British Council English material should remain supporting material rather than become parallel curricula.

### Paused / On-demand

- Japanese and UX: Later.
- Career/job boards: Reference/on-demand.
- Shopping and one-off transactional pages: archive/remove after they stop being useful.
